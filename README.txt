TYRETRACK WINDOWS PORTABLE
1. Extract the ZIP completely (do not run inside the ZIP).
2. Open TyreTrack folder, double-click Start_TyreTrack.bat.
3. The model is bundled into _internal; keep the whole folder together.
4. Configure Gmail app password in %%LOCALAPPDATA%%\TyreTrack\email_config.ini (never upload secrets to GitHub).
5. Counts, reports and recordings are saved beside TyreTrack.exe.
6. OAK-D S2 PoE: test discovery/IP and camera operation on the Australian PC.
7. This is an automated Windows build, not a hardware-validated production release.
If startup fails, inspect data\tyretrack.log.
